# 编辑器使用指南

## 界面

```
┌ 顶栏：项目名 · 语言 · 运行/停止 · 撤销/重做 · 新建/打开/保存 · 缩放 · 帮助/文档 ┐
│ 工具箱（搜索 + 分类）│          画布（积木 + 状态栏）          │ 属性 / 变量 / 控制台 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **工具箱**：按类别分组，点击分类标题可折叠/展开；可搜索（按名称或块类型），回车插入，或直接拖到画布。悬停约 0.6 秒出现提示卡（名称、块类型、一句话说明），点提示卡里的「更多」打开详细信息：语句类型/子类型、支持的操作系统、是否 C 形、是否可扩展、参数个数、形参名称与接受类型、返回值类型。
- **画布**：每个脚本是独立的 hat 块。空白处拖拽平移，滚轮缩放（见下）。
- **属性面板**：选中块后显示类型、说明、字段与端口，以及脚本顺序（上移/下移）；可清空值端口、删除块。
- **变量面板**：只读的运行状态面板，列出程序运行时真正存在的变量与当前值；变量由「创建变量」「删除变量」积木在运行时声明，暂停、单步或跟踪时随执行刷新。
- **控制台 / 问题**：运行输出；状态栏「问题」打开校验诊断列表（含块路径）。

## 基本操作

1. 把「当程序启动时」拖到画布。
2. 把「输出」拖进 hat 的栈槽。
3. 在属性面板把内容改成 `Hello, world!`（示例项目已预填）。
4. 点「运行」→ 控制台出现输出；「停止」可中止长循环。
5. 「保存」导出 `.nblk` 文本文件；「打开」读回 `.nblk`（兼容旧的 `.nexusblocks.json`）；编辑会自动存到浏览器本地。

可扩展积木：

- `连接`：积木末尾有 `+` / `−`，可增减连接项（2–8 段）。
- `如果`：语句头上的 `+` / `−` 调整扩展值（0–4）。0 只有「如果」；1 变成「如果-否则」；2 起每增加 1 就多一条「否则如果」，最后仍是「否则」。每个否则如果分支都有自己的条件和执行槽。
- 函数定义：参数输入框后的 `+` / `−` 会追加或删除一个 `argN: any` 参数（最多 8 个）；参数语法仍是 `名称:类型`。

拖拽规则：

| 拖的块 | 可放到 |
| --- | --- |
| 工具箱里的 hat（如“当程序启动时”） | 画布空白处（在末尾追加新脚本） |
| 语句（如“输出”） | 栈槽、另一条语句上方/下方、画布（自动包一层脚本） |
| 表达式（如“文本”） | 类型兼容的值端口（`text` 端口接受数字/布尔） |
| 语句 / 表达式 | 工具箱左侧面板（松开即删除，可撤销） |

拖到非法位置会回弹并提示。脚本顺序由文档里的 `scripts` 数组决定：画布按数组顺序左对齐、从上到下排列，所以画布上的 hat 不再拖动换位；选中 hat 后可在属性面板的「脚本顺序」里点上移/下移箭头调整位置，也可以直接编辑 `.nblk` 里脚本的顺序。把积木拖到工具箱时，面板会高亮并显示“把积木拖到这里可删除”；删除整条脚本请选中 hat 后按 `Delete`。

## 跨文件导入

在工具箱「模块」分类里有三种顶栏积木，放在画布顶层即可（它们是声明，运行时会先载入，不会作为普通语句执行）：

| 积木 | 作用 |
| --- | --- |
| `导入[文件]` | 导入文件里全部函数 |
| `从[文件]导入[函数]` | 只导入指定函数 |
| `从[文件]导入[函数]作为[名称]` | 导入并用本地名称显示，调用块与校验都用该名称 |

- 文件名是程序文件路径（`.nblk`）：桌面端支持绝对路径、`~/…` 或主目录相对路径；浏览器端读取 localStorage 文件区。
- 被导入文件里的函数和变量会合并进当前项目，被导入函数里的调用会照常生成调用块（工具箱「函数」分类）。
- 修改导入积木或编辑被导入文件后，点顶栏「重新载入导入」刷新调用块；导入失败会显示在「问题」面板。
- 导入只加载函数定义，不执行被导入文件的顶层脚本。

## 错误处理

工具箱「控制」分类里有 5 种错误处理积木：

| 积木 | 作用 |
| --- | --- |
| `尝试` | 容器：`尝试主体` 栈放要保护的语句，`捕获分支` 栈里挂捕获积木 |
| `抛出[异常]` | 抛出任意值作为异常 |
| `捕获` | 捕获任意异常；只能放进尝试的捕获分支 |
| `捕获[异常]` | 只捕获指定类型（任意/运行时错误/文本/数字/布尔/列表/字典） |
| `捕获[异常]到[变量]` | 捕获后把错误信息转成字符串写入该变量（不存在时自动创建），再执行处理体 |

- 捕获分支按顺序匹配；没有分支匹配时异常继续向外抛出，直到运行以错误结束。
- 运行时错误（例如除以零、类型不匹配）也能被捕获，过滤条件选「运行时错误」；捕获到的文本使用界面当前语言。
- `停止` 与 `跳出循环` 不会被捕获，仍按原语义中断或跳出。
- 尝试之间的 `捕获` 积木不要直接拖到画布或普通语句栈：校验会报「捕获积木只能放在尝试积木的捕获分支里」，拖拽时也只允许放进尝试的「捕获分支」槽。

## 调试

调试状态只保存在编辑器里，会自动保存到本地，但**不会写入 `.nblk` 代码文件**，解释器也不会读取代码文件里的调试信息。

- **暂停 / 继续**：运行中按「暂停」（`F8`）会在下一条语句执行前挂起；挂起后按「继续」（`F8`）恢复运行。工具栏的这两个按钮在运行/跟踪时可用。
- **步进**：挂起后按「步进」（`F10`）只执行当前一条语句，然后停在下一步。
- **断点**：只有动作语句能设断点。选中语句后，在右侧属性面板打开「断点」开关，语句会红色高亮；运行到它之前会自动暂停。
- **跟踪运行**：按「跟踪」后以较慢速度逐条执行，每条语句前有延迟，画布上当前语句会高亮。
- **实时变量**：跟踪或暂停时，左侧变量面板显示变量的当前值。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `F8` | 暂停 / 继续 |
| `F10` | 步进（挂起时）|
| `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`） | 撤销 / 重做 |
| `Delete` / `Backspace` | 删除选中块 |
| `Ctrl+S` | 下载项目文件 |
| 画布空白处拖拽，或中键拖拽 | 平移画布 |
| 滚轮 | 平移（默认） |
| `Ctrl` + 滚轮 | 以指针位置为中心缩放 |

## 语言

顶栏语言选择器立即切换界面、积木标签与运行消息，偏好保存在 localStorage（`nexus-blocks:locale`）。首次打开会读取浏览器语言；不支持时回退到简体中文。

## 自动保存

编辑器在每次修改后约 450ms 写入 `localStorage` 的 `nexus-blocks:autosave`（完整文档 JSON，内部实现）。「新建」会先确认，然后重置为示例文档。

## 已知限制

- 暂不支持复制/粘贴、多选。
- 解释器不设步数/递归上限：死循环或过深递归会一直跑下去，由用户按「停止」或自行修正。
- 画布整树重渲染；超大项目（数千块）可能掉帧。
