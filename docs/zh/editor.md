# 编辑器使用指南

## 界面

```
┌ 顶栏：项目名 · 语言 · 运行/停止 · 撤销/重做 · 新建/打开/保存 · 缩放 · 帮助/文档 ┐
│ 工具箱（搜索 + 分类）│          画布（积木 + 状态栏）          │ 属性 / 变量 / 控制台 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- **工具箱**：按类别分组；可搜索（按名称或块类型），回车插入，或直接拖到画布。
- **画布**：每个脚本是独立的 hat 块。空白处拖拽平移，滚轮缩放（见下）。
- **属性面板**：选中块后显示类型、说明、字段与端口；可清空值端口、删除块。
- **变量面板**：新建/删除变量，点击高亮引用位置。
- **控制台 / 问题**：运行输出；状态栏「问题」打开校验诊断列表（含块路径）。

## 基本操作

1. 把「当程序启动时」拖到画布。
2. 把「输出」拖进 hat 的栈槽。
3. 在属性面板把内容改成 `Hello, world!`（示例项目已预填）。
4. 点「运行」→ 控制台出现输出；「停止」可中止长循环。
5. 「保存」导出 `.nexusblocks.json`；「打开」读回文件；编辑会自动存到浏览器本地。

拖拽规则：

| 拖的块 | 可放到 |
| --- | --- |
| hat（如“当程序启动时”） | 画布空白处（新建脚本） |
| 语句（如“输出”） | 栈槽、另一条语句上方/下方、画布（自动包一层脚本） |
| 表达式（如“文本”） | 类型兼容的值端口（`text` 端口接受数字/布尔） |

拖到非法位置会回弹并提示。拖动 hat 会移动整条脚本。

## 跨文件导入

在工具箱「模块」分类里有三种顶栏积木，放在画布顶层即可（它们是声明，运行时会先载入，不会作为普通语句执行）：

| 积木 | 作用 |
| --- | --- |
| `导入[文件]` | 导入文件里全部函数 |
| `从[文件]导入[函数]` | 只导入指定函数 |
| `从[文件]导入[函数]作为[名称]` | 导入并用本地名称显示，调用块与校验都用该名称 |

- 文件名是程序文件路径（`.nexusblocks.json`）：桌面端支持绝对路径、`~/…` 或主目录相对路径；浏览器端读取 localStorage 文件区。
- 被导入文件里的函数和变量会合并进当前项目，被导入函数里的调用会照常生成调用块（工具箱「函数」分类）。
- 修改导入积木或编辑被导入文件后，点顶栏「重新载入导入」刷新调用块；导入失败会显示在「问题」面板。
- 导入只加载函数定义，不执行被导入文件的顶层脚本。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`） | 撤销 / 重做 |
| `Delete` / `Backspace` | 删除选中块 |
| `Ctrl+S` | 下载项目文件 |
| 画布空白处拖拽，或中键拖拽 | 平移画布 |
| 滚轮 | 平移（默认） |
| `Ctrl` + 滚轮 | 以指针位置为中心缩放 |

## 语言

顶栏语言选择器立即切换界面、积木标签与运行消息，偏好保存在 localStorage（`nexus-blocks:locale`）。首次打开会读取浏览器语言；不支持时回退到简体中文。

## 自动保存

编辑器在每次修改后约 450ms 写入 `localStorage` 的 `nexus-blocks:autosave`（完整文档 JSON）。「新建」会先确认，然后重置为示例文档。

## 已知限制

- 暂不支持复制/粘贴、多选、函数块。
- 解释器为同步语义（async 容器），长循环用步数上限保护（默认 100,000 步）。
- 画布整树重渲染；超大项目（数千块）可能掉帧。
