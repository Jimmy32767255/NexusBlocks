# 国际化（i18n）

编辑器、积木标签、运行时消息与文档共用一套 message key。默认语言：**简体中文**（`zh-CN`）；回退语言：**英文**（`en`）。

## 语言包

```
packages/i18n/src/catalogs/
  en.ts     英文，扁平 key
  zh-CN.ts  简体中文，键与 en 一一对应
  index.ts  LOCALES / DEFAULT_LOCALE / FALLBACK_LOCALE / catalogs / resolveLocale
```

key 采用点分层级，但文件里是扁平字符串：

```ts
"canvas.emptyTitle": "开始搭建",
"block.io.print.label": "输出",
"block.io.print.port.text": "内容",
"inspector.kind.expression": "表达式",
"runtime.error.badType": "需要 {to} 类型，但得到的是 {from} 类型",
```

## 使用

编辑器侧封装（`apps/editor/src/i18n.ts`）：

```ts
import { t, hasKey, currentLocale, setUiLocale } from "./i18n.ts";

t("canvas.blocks", { count: 3 }); // 插值：{count}
if (hasKey("docs.title")) { ... } // 缺少词条时做兜底
setUiLocale("en");                 // 写入 localStorage 并触发重渲染
```

运行时侧：`runProject` 不返回人类可读字符串，而是返回 `messageKey` 与 `params`：

```ts
{ kind: "error", messageKey: "runtime.error.badType",
  params: { to: "number", from: "text" }, blockId: "b_12" }
```

编辑器在渲染日志时翻译它，因此输出跟随界面语言。语言包缺失时会回退到英文，并在开发模式下打日志。

## 直接使用包

```ts
import { createTranslator, catalogs, en, zhCN, missingKeys } from "@nexus/i18n";

const translator = createTranslator({
  locale: "zh-CN",
  catalogs,
  fallbackLocale: "en",
});

translator.t("block.io.print.label"); // 输出
```

`missingKeys(reference, target)` / `extraKeys(...)` 用于检查语言包是否对齐；`packages/i18n/test/catalogs.test.ts` 用它保证中英文 key 完全一致。

## 新增语言

1. 新建 `packages/i18n/src/catalogs/<tag>.ts`，导出同构 `Catalog`（`Record<string, string>`），先复制英文再翻译。
2. 在 `catalogs/index.ts` 的 `catalogs` 与 `LOCALES` 中登记名称（`LOCALES` 提供语言选择器标签）。
3. 补测试：`missingKeys` 为空、`extraKeys` 为空。
4. 编辑器语言切换会自动出现新选项，无需改 UI 代码。

## 约定

- **不要拼接句子**：用带占位符的整句 key（`{count}`、`{name}`），避免不同语言的语序问题。
- **不要翻译标识符**：块类型（`io.print`）、端口名（`text`）、诊断 code（`block.unknownType`）保持英文；翻译只作用于 label/description 与 messageKey 指向的文本。
- **新词条两边同时加**：`pnpm test` 会失败如果中英文 key 不对齐。
- **运行时错误必须有 messageKey**：`ctx.fail(key, params)`，不要在积木里写死英文句子。
